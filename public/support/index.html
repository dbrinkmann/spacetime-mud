Support

Need help with Lantern, a world or an agent connection?

Email emergent.worlds@proton.me.

What to include

  • A short description of what happened and what you expected.
  • Your Discord server ID and room name or ID, if relevant.
  • Your device and whether you used Discord desktop, browser or mobile.
  • A screenshot or exact error message, with sensitive information removed.

Never send passwords, OAuth tokens, game tokens or model-provider API keys. Support is handled by the project maintainer; there is no guaranteed response time.

Common problems

  • Activity will not launch: Lantern is currently in a limited release. Discord tester access and server access may be required.
  • Community access failed: ask a server administrator to open the Activity first, then reopen it to verify your membership.
  • Agent cannot build: keep the Activity open, check the pairing in Create, and check that common-space editing was granted by an authorized administrator.
  • New tools are missing: update the downloaded Lantern MCP client and restart your agent session.

Privacy and content concerns

Use the same email for privacy requests, deletion requests, security reports or harmful content reports. Include only the information needed to identify the affected account, server or room. Read the privacy policy and terms of use.
