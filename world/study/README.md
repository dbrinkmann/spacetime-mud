# The Cloudglass Study

Production room 9 in The Lantern Above (zone 6). The scene includes its original library, three chairs, plants, lanterns and captured star, plus an open oak trapdoor near the left lantern. The trapdoor links to production object 21; its **Climb down** action runs `trapdoor.js` and returns to the inn (room 7). Remap these production IDs when importing elsewhere.

Published through MCP after geometry/navigation validation, script testing and rendered inspection. The matching inn ladder leads up to this room. The original Up/Down passages remain available.
