# Original implementation

The original Rust module, React client using SpacetimeDB 0.6, and Python/OpenAI agent are retained here for history and reference. They are not part of the current build or deployment. Use the root README for the working TypeScript implementation.

The original game's central idea remains: players begin in the Nexus and build the shared world through an agent, then explore and roleplay with the characters they create. The unmerged upstream `zone-generation` branch is research context, not a completed feature of this release.
